# Scientific Data Analysis in R

A small portfolio of academic data-analysis work from my BSc/MSc training in medical, molecular and health science.

My primary programming experience has been in **R/RStudio**, used for statistical analysis, scientific visualisation, meta-analysis and genomics-related coursework. I have also worked with Python for scientific/numerical modelling and with a range of bioinformatics tools.

## Featured project

### Student performance: study hours, sleep and academic score

An R Markdown analysis examining whether weekly study hours and nightly sleep duration predict total academic score.

**Methods used**
- data inspection and cleaning
- descriptive statistics
- ANOVA
- Pearson correlation
- multiple linear regression
- regression diagnostics
- ggplot2 visualisation
- data reshaping for comparative plots

[View the project →](student-performance-analysis/)

## Additional computational work

## About this repository

The featured project began as collaborative university coursework by **Alaa Moussa and Jozelina Gales**. This public version is a cleaned portfolio edition of the original analysis. Collaborative authorship is retained explicitly.

The original teaching dataset is not redistributed here. The analysis file uses a relative data path so that the workflow can be reproduced if the dataset is available.
